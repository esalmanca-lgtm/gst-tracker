Connect to Supabase
Your data will be stored in Supabase — a free, real-time database. All your team members will see live updates when stages are changed. Follow the steps below to set up.
1
Create a free Supabase account
Go to supabase.com → click "Start your project" → sign up with GitHub or email. It's completely free.
2
Create a new project
Click "New Project" → name it "gst-tracker" → choose a region close to India (ap-south-1 or Singapore) → set a database password → click "Create new project". Wait ~2 minutes for it to spin up.
3
Run the database setup SQL
In your Supabase project → go to SQL Editor → click "New query" → paste and run this SQL:
-- GST Tracker Schema CREATE TABLE IF NOT EXISTS clients ( id uuid PRIMARY KEY DEFAULT gen_random_uuid(), name text NOT NULL, gstin text, freq text DEFAULT 'M', rent_amount numeric DEFAULT 0, rcm_applicable boolean DEFAULT false, email text DEFAULT '', phone text DEFAULT '', portal_username text DEFAULT '', portal_password text DEFAULT '', notes text DEFAULT '', whatsapp_group text DEFAULT '', created_at timestamptz DEFAULT now() ); CREATE TABLE IF NOT EXISTS filings ( id uuid PRIMARY KEY DEFAULT gen_random_uuid(), client_id uuid REFERENCES clients(id) ON DELETE CASCADE, period_id text NOT NULL, g1 jsonb DEFAULT '{"statuses":{}}', g3 jsonb DEFAULT '{"statuses":{}}', updated_at timestamptz DEFAULT now(), UNIQUE(client_id, period_id) ); CREATE TABLE IF NOT EXISTS periods ( id text PRIMARY KEY, label text NOT NULL, type text DEFAULT 'M', fy text, sort_order integer DEFAULT 0, created_at timestamptz DEFAULT now() ); CREATE TABLE IF NOT EXISTS system_config ( key text PRIMARY KEY, value jsonb NOT NULL, updated_at timestamptz DEFAULT now() ); CREATE TABLE IF NOT EXISTS followups ( id uuid PRIMARY KEY DEFAULT gen_random_uuid(), client_id uuid REFERENCES clients(id) ON DELETE CASCADE, category text NOT NULL, wa_count integer DEFAULT 0, stage text DEFAULT 'whatsapp', notes text DEFAULT '', updated_at timestamptz DEFAULT now(), UNIQUE(client_id, category) ); -- Seed default periods INSERT INTO periods (id, label, type, fy, sort_order) VALUES ('Jun-2025','Jun 2025','M','FY25-26',1), ('May-2025','May 2025','M','FY25-26',2), ('Apr-2025','Apr 2025','M','FY25-26',3), ('Q4-FY25','Q4 FY24-25','Q','FY24-25',4), ('Mar-2025','Mar 2025','M','FY24-25',5), ('Feb-2025','Feb 2025','M','FY24-25',6), ('Jan-2025','Jan 2025','M','FY24-25',7), ('Q3-FY25','Q3 FY24-25','Q','FY24-25',8), ('Dec-2024','Dec 2024','M','FY24-25',9), ('Nov-2024','Nov 2024','M','FY24-25',10), ('Oct-2024','Oct 2024','M','FY24-25',11), ('Q2-FY25','Q2 FY24-25','Q','FY24-25',12), ('Sep-2024','Sep 2024','M','FY24-25',13), ('Aug-2024','Aug 2024','M','FY24-25',14), ('Jul-2024','Jul 2024','M','FY24-25',15), ('Q1-FY25','Q1 FY24-25','Q','FY24-25',16), ('Jun-2024','Jun 2024','M','FY24-25',17), ('May-2024','May 2024','M','FY24-25',18), ('Apr-2024','Apr 2024','M','FY24-25',19) ON CONFLICT (id) DO NOTHING; -- Enable realtime ALTER PUBLICATION supabase_realtime ADD TABLE clients; ALTER PUBLICATION supabase_realtime ADD TABLE filings; ALTER PUBLICATION supabase_realtime ADD TABLE periods; ALTER PUBLICATION supabase_realtime ADD TABLE system_config; -- Allow public access (no auth for now) ALTER TABLE clients ENABLE ROW LEVEL SECURITY; ALTER TABLE filings ENABLE ROW LEVEL SECURITY; ALTER TABLE periods ENABLE ROW LEVEL SECURITY; ALTER TABLE system_config ENABLE ROW LEVEL SECURITY; CREATE POLICY "public_all_clients" ON clients FOR ALL TO anon, authenticated USING (true) WITH CHECK (true); CREATE POLICY "public_all_filings" ON filings FOR ALL TO anon, authenticated USING (true) WITH CHECK (true); CREATE POLICY "public_all_periods" ON periods FOR ALL TO anon, authenticated USING (true) WITH CHECK (true); CREATE POLICY "public_all_config" ON system_config FOR ALL TO anon, authenticated USING (true) WITH CHECK (true); GRANT USAGE ON SCHEMA public TO anon; GRANT ALL ON ALL TABLES IN SCHEMA public TO anon; GRANT ALL ON ALL SEQUENCES IN SCHEMA public TO anon;
4
Get your API credentials
In Supabase → go to Settings → API. Copy the "Project URL" and "anon public" key below.
